JSON

curl -X POST {{ request.url_root }}api/v1/json/format \
  -H "Content-Type: application/json" \
  -d '{"text": "{\"a\":1}"}'

POST /api/v1/json/format and /api/v1/json/minify

Base64

POST /api/v1/base64/encode and /decode. Optional "urlsafe": true when encoding.

Hashes

POST /api/v1/hash returns md5, sha1, sha256 and sha512.

UUID

GET /api/v1/uuid?count=5 returns up to 500 v4 UUIDs.

Responses

Success: {"result": ...}. Errors: {"error": "..."} with status 400, 422 or 429.
